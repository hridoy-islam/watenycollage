# Employee & Student Management System

A modern management platform built with React, TypeScript, and Shadcn UI to streamline student administration, employee management, recruitment, rota planning, compliance tracking, and workforce operations.

<div align="center">
  <strong>Built with React, TypeScript, Vite, Tailwind CSS, and Shadcn UI</strong>
</div>

---

## 🌐 Branch Structure

This repository contains multiple branches for different organizations and management systems.

| Branch       | System                                                |
| ------------ | ----------------------------------------------------- |
| `main`       | **Watney College Student and Teacher Management System**          |
| `cyberpeers` | **Cyberpeers Recruitment & Employee Management System**             |
| `caresquare` | **CareSquare Recruitment & Employee Management System**             |

## 🚀 Overview

This platform provides comprehensive management solutions for educational institutions, healthcare providers, recruitment agencies, and workforce management organizations.

### Core Features

* Employee Management
* Student Management
* Recruitment Management
* Applicant Tracking System (ATS)
* Attendance Management
* Compliance Tracking
* Leave Management
* Role & Permission Management
* Document Management
* Dashboard & Analytics
* Reporting System
* Secure Authentication
